# 1.1.0

- `우~라!` 줄바꿈 없는 출력, `시사!` 문자열 연결, `모몽가!` 숫자→문자열 변환.
- 컴파일러·문법 안내·구문 강조·자동완성·코드 조각 갱신.

# 변경 기록

## 1.0.0 — 2026-10-16

- 언어 표준·컴파일러·확장 버전을 1.0.0으로 확정한 첫 정식 배포.
- 숫자 냠?·문자열 하아?, 다중 숫자 입력, 정수 배열 야얏!, 개행 우이! 포함.
- 기존 함수·반응 분기·반복·형 변환·범위·오류 규칙을 정식 표준으로 문서화.
- 0.5.0 숫자 입력의 하아?는 냠?로 수정해야 함.
- GitHub Releases에서 VSIX와 SHA-256을 제공.


## 0.6.0
